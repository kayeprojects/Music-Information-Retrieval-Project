# Tugas 2 — Retrieval Artikel Musik Indonesia

Proyek ini mengubah dataset hasil crawling ANTARA News pada Tugas 1 menjadi mesin pencari classical Information Retrieval.

## Struktur

```text
tugas2_ir/
├── data/
│   ├── dataset_crawling_ir.csv
│   └── dataset_preprocessed.csv
├── index/inverted_index.json
├── src/
│   ├── preprocessing.py
│   ├── indexing.py
│   ├── boolean_retrieval.py
│   ├── tfidf_retrieval.py
│   ├── bm25.py
│   └── search_engine.py
├── evaluation/
│   ├── queries.csv
│   ├── evaluate.py
│   ├── ground_truth.csv          # generated by evaluation
│   ├── metrics.csv               # generated by evaluation
│   └── ranking_comparison.csv    # generated by evaluation
├── tests/test_ir.py
├── app.py
├── run_pipeline.py
└── requirements.txt
```

## Instalasi dan build

Python 3.10+ direkomendasikan. Dari folder ini jalankan:

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python run_pipeline.py
python -m evaluation.evaluate
python verify_project.py
python -m unittest tests.test_ir -v
```

`run_pipeline.py` menyalin `../dataset_musik_indonesia_antaranews.csv` sebagai input awal jika file di `data/` belum ada, membersihkan baris kosong/duplikat, memproses korpus, lalu membuat dataset preprocessed dan JSON inverted index.

## Mesin pencari

CLI:

```bash
python app.py --query "royalti lagu Indonesia" --model bm25 --top-k 10
python app.py --query "musisi AND royalti" --boolean
```

Antarmuka Streamlit:

```bash
streamlit run streamlit_app.py
```

Query Boolean mendukung `AND`, `OR`, `NOT`, dan tanda kurung; AND memiliki prioritas lebih tinggi daripada OR. Untuk pencarian berperingkat, pilih `tfidf` atau `bm25`.

## Preprocessing dan model

- Normalisasi Unicode dan case folding, buang URL/tanda baca/angka, lalu tokenisasi huruf.
- Stopword Bahasa Indonesia buatan proyek dibuang; kata negasi seperti `tidak`, `bukan`, `belum`, dan `tanpa` dipertahankan karena dapat membawa makna query.
- Stemming memakai aturan imbuhan ringan yang deterministik untuk efisiensi korpus; bukan lemmatizer KBBI penuh. Aturan dan pengecualian ada di `src/preprocessing.py`.
- Judul digabung dua kali dengan isi untuk memberi bobot judul lebih besar pada pencarian.
- TF-IDF memakai `TF = 1 + ln(tf)` dan `IDF = ln((N+1)/(df+1)) + 1`; skor diranking dengan cosine similarity.
- BM25 memakai IDF positif `ln(1 + (N-df+0.5)/(df+0.5))`, `k1=1.2`, dan `b=0.75`.
- Inverted index menyimpan postings `{doc_id, tf}`, DF, dan panjang dokumen.

## Evaluasi

`evaluation/queries.csv` berisi sepuluh query bertopik musik dengan aturan relevansi yang eksplisit. `python -m evaluation.evaluate` membuat ground truth rule-based yang dapat diaudit dari bukti istilah di judul/lead, mengukur Precision@10, Recall@10, F1@10 untuk dua model, dan menghitung overlap Top-10. Ground truth ini adalah baseline kriteria domain—tinjau manual sebelum menyebutnya penilaian ahli.

## Batasan

Stemming aturan ringan dapat under/over-stem dibanding Sastrawi; hasil perlu ditinjau pada sampel sebelum laporan final. Label relevansi evaluasi dibentuk dengan aturan yang bisa dijelaskan dan perlu validasi manual. UI Streamlit adalah nilai tambah; CLI tetap disediakan untuk lingkungan tanpa Streamlit.
